# Northframe

Marketing site for a student-focused web design studio. Next.js 16, Tailwind v4, Motion.

```bash
npm install
npm run dev        # http://localhost:3000, style guide at /design-system
npm run build
npm run lint && npm run typecheck && npm run contrast
```

Project memory and conventions: `CLAUDE.md`. Roadmap: `docs/ROADMAP.md`.
